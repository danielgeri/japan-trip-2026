# 🇯🇵 Japan Family Trip 2026: Master Web Guide
A mobile-friendly, interactive travel web application built for the Geri family trip to Japan (October 15 – October 27, 2026).

## Features
- **Interactive Daily Itinerary:** Day 1 to Day 12 with morning, afternoon stroller-nap/cafe, and evening time blocks.
- **Flight & Booking Ledger:** Confirmation numbers, JAL Row 36 seat assignments, hotel addresses, phone numbers, and check-in instructions.
- **In-Flight Survival Checklist:** Interactive checkboxes (saves state to `localStorage` on mobile devices) for flight packing, ear pressure protocols, and toddler entertainment.
- **Regional Omiyage & Snack Guide:** Curated souvenir guides for Hokkaido, Kyoto, Kamakura, and Tokyo.
- **Maria & Kayden Guide:** Japanese phrase cards for maternity marks, well-cooked eggs, child chairs, and caffeine-free drink recommendations.
- **Live Sync:** Direct links to the Wanderlog trip plan and Google Maps navigation.
